# Estatísticas FC Gaia

Área privada de estatísticas de jogo do FC Gaia Basquetebol: https://andreferraz12.github.io/fcgaia-estatisticas/

- Os jogos e os plantéis vêm do site do calendário (`Fcgaiacalendario/data/jogos.json`).
- `utilizadores.json` é a lista de utilizadores, atualizada pela própria app no separador Utilizadores. Só tem hashes, nunca palavras-passe.
- `fonte/` tem o código-fonte (`stats_src.html`), o gerador (`build_stats.py`) e o contexto do projeto (`LEIA-ME-estatisticas.md`).
